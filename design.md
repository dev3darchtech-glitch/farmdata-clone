# Design System — Nông Nghiệp Capture Data (Garden Theme)

A locked design system for this app based on the **Hollowback Apiary (Garden)** template DNA.
Every page redesign reads this file before emitting code.

## Genre
editorial (Garden cluster)

## Macrostructure Family
- Marketing / Auth pages: Field Almanac Masthead + Single-card Hero (`H1-Marquee`)
- App / Dashboard pages: Almanac Fact Sheet + Catalogue Cards (`F6-Product-grid`)
- Capture & Input pages: Stacked Step Almanac (`Long-Document`)

## Theme (Garden / Hollowback Apiary DNA)
- `--color-paper`:       `#FBF8EF` (Warm Cream / Natural Linen)
- `--color-paper-2`:     `#F3EDE0` (Soft Sand Card Surface)
- `--color-paper-3`:     `#EAE2D0` (Subtle Input Background)
- `--color-ink`:         `#1E2920` (Deep Forest Charcoal)
- `--color-ink-2`:       `#4A574D` (Muted Sage / Olive Gray)
- `--color-rule`:        `#D8CFBC` (Delicate Hairline Rule)
- `--color-accent`:      `#B8621B` (Warm Terracotta / Amber)
- `--color-accent-soft`: `#F4E8D8` (Soft Honey Fill)
- `--color-success`:     `#2D6A4F` (Deep Botanical Green)
- `--color-error`:       `#9A3412` (Earthy Rust Red)

## Typography
- Display: `Georgia`, `ui-serif`, `serif` (weight: 700, normal style)
- Body: `system-ui`, `-apple-system`, `sans-serif` (weight: 400/500/600)
- Mono / Eyebrows: `SFMono-Regular`, `Menlo`, `Monaco`, `monospace` (weight: 600, uppercase, letter-spacing: 0.8px)

## UI Voice & Styling Rules
- Hairline rules (`1px solid #D8CFBC`) separating card sections and header bars.
- Field Almanac dateline headers (e.g. `FIELD ALMANAC · NÔNG NGHIỆP DATA 2026`).
- Section titles with subtle bullet/leaf flourishes.
- Status badges and lot tags (e.g. `LOT 14-A · GERMINATION STAGE`).
- Tactile buttons with solid amber `#B8621B` fill or hairline ghost outlines.
